# Best Spices and Agro Impex Pvt Ltd — B2B Website Demo

A responsive, heritage-themed B2B import/export demo website for **Best Spices and Agro Impex Pvt Ltd**, ready to host on GitHub Pages across mobile, tablet, and desktop devices.

## Folder Structure

- `index.html` — Main responsive storefront page
- `styles.css` — Natural heritage theme, typography, smooth animations, and custom radio buttons
- `app.js` — Interactive catalog filters, radio-button pack pricing, cart drawer, INR/USD switcher, bulk container calculator, and demo proforma checkout
- `assets/images/` — Optimized brand logo, hero banner, and studio spice product photography

## How to Publish on GitHub Pages

1. Extract this ZIP file on your computer.
2. Create a new public repository on GitHub (for example, `best-spices-agro-impex`).
3. Upload all extracted files (`index.html`, `styles.css`, `app.js`, `README.md`, and the `assets/` folder) directly into the root of the repository.
4. Go to **Settings → Pages** in your GitHub repository.
5. Under **Build and deployment → Source**, choose **Deploy from a branch**, select **`main`** and **`/ (root)`**, then click **Save**.
6. Wait 1–2 minutes and open your live GitHub Pages URL on any phone, tablet, or computer.

## Customizing Demo Details

- Update demo phone numbers, email addresses, and registered office address directly in `index.html` under `#bulk-orders` and `#contact`.
- Update indicative INR/USD prices, pack weights, or spice varieties in the `SPICES` array inside `app.js`.
